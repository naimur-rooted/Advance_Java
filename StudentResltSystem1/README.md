# Student Result System (Java + MySQL)

## Overview
This project demonstrates how to connect Java with MySQL using JDBC.

## Collections
- Used Array and HashMap to store student names and marks.
- Helped organize and quickly access student data.

## JDBC
- Steps: Load driver → Connect → Create Statement → Execute SQL → Close.
- SQL used: CREATE DATABASE, CREATE TABLE, INSERT, SELECT.
